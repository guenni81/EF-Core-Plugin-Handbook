\chapter{Glossary}\label{app:C}

\begin{datatable}{H{0.60}H{1.40}}
  \textbf{Term} & \textbf{Explanation} \\
  \tablehead
  Annotation & Key-value metadata on a model element. \\
  \tablerule
  ConfigurationSource & Origin of a piece of metadata (Explicit, DataAnnotation,
  Convention); determines who may override whom. \\
  \tablerule
  Convention & Rule that adapts the model automatically while it is built. \\
  \tablerule
  Decorator & Service that wraps the previously registered implementation and delegates to
  it; composes with other plugins (chapter~\ref{ch:registering-services}). \\
  \tablerule
  Design-time model & Complete model with all annotations; basis for migrations.
  Counterpart: the lean runtime model. \\
  \tablerule
  Differ & \code{IMigrations\allowbreak{}Model\allowbreak{}Differ}; compares two relational
  models. \\
  \tablerule
  Funcletizer & First query stage; evaluates expressions without data reference in .NET. \\
  \tablerule
  Identity resolution & The same entity yields the same instance: with tracking through the
  change tracker, otherwise optionally per query. \\
  \tablerule
  Materializer & Part of the shaper that creates an entity: constructor, then properties and
  fields. \\
  \tablerule
  Nullability processor & Query stage that evaluates NULL semantics and optimizes
  comparisons; must know custom SQL nodes. \\
  \tablerule
  Shaper & Compiled expression tree per query shape that builds the result from the rows of
  the \code{Db\allowbreak{}Data\allowbreak{}Reader}. \\
  \tablerule
  SqlExpression & Node in the SQL expression tree; custom nodes for syntax that is not a
  function. \\
  \tablerule
  Runtime annotation & Annotation read at run time, which must therefore survive in the
  runtime and compiled model. \\
  \tablerule
  Runtime annotation (EF API) & Narrower meaning in EF's API: a value that code stores on
  the finished model only
  (\code{Get\allowbreak{}Or\allowbreak{}Add\allowbreak{}Runtime\allowbreak{}Annotation\allowbreak{}Value}),
  for example as a cache; it never appears in the snapshot or in migrations. \\
  \tablerule
  Internal service provider & EF's own DI container per configuration. \\
  \tablerule
  Pubternal & Publicly visible but internal API without compatibility guarantees (EF1001).
  \\
  \tablerule
  Relational model & Tables, columns, indexes, derived from the EF model. \\
  \tablerule
  RLS & Row Level Security: row filters enforced by the database itself. \\
  \tablerule
  Snapshot & Generated C\# code with the model state of the last migration. \\
  \tablerule
  Type mapping & Connection between CLR type and database type including conversion,
  comparison and literals. \\
\end{datatable}

\chapter{Debugging toolbox}\label{app:D}

When a plugin does not behave as expected, the question is almost always one of six. Each
technique below is checked in \code{Debugging\allowbreak{}Tests}.

\begin{datatable}{H{0.61}H{1.39}}
  \textbf{Question} & \textbf{Technique} \\
  \tablehead
  Is my annotation in the model? &
  \code{To\allowbreak{}Debug\allowbreak{}String(\allowbreak{}Metadata\allowbreak{}Debug\allowbreak{}String\allowbreak{}Options.\allowbreak{}Long\allowbreak{}Default)}
  on the design-time model \\
  \tablerule
  Which implementation of a single service won? &
  \code{context.\allowbreak{}Get\allowbreak{}Service<\allowbreak{}IMigrations\allowbreak{}Sql\allowbreak{}Generator>(\allowbreak{}).\allowbreak{}Get\allowbreak{}Type(\allowbreak{})}
  \\
  \tablerule
  Is my convention registered? &
  \code{Get\allowbreak{}Service<\allowbreak{}IConvention\allowbreak{}Set\allowbreak{}Builder>(\allowbreak{}).\allowbreak{}Create\allowbreak{}Convention\allowbreak{}Set(\allowbreak{})},
  then e.g. \code{Model\allowbreak{}Finalizing\allowbreak{}Conventions} \\
  \tablerule
  What does the query look like before and after translation? &
  \code{query.\allowbreak{}Expression.\allowbreak{}Print(\allowbreak{})} and
  \code{query.\allowbreak{}To\allowbreak{}Query\allowbreak{}String(\allowbreak{})} \\
  \tablerule
  At which stage of the pipeline does something change? &
  \code{Log\allowbreak{}To} at debug level with
  \code{Core\allowbreak{}Event\allowbreak{}Id.\allowbreak{}Query\allowbreak{}Compilation\allowbreak{}Starting}
  (tree after the funcletizer) and
  \code{Query\allowbreak{}Execution\allowbreak{}Planned} (\code{Select\allowbreak{}Expression}
  and shaper), chapter~\ref{ch:the-query-pipeline} \\
  \tablerule
  Does my plugin log? &
  \code{Log\allowbreak{}To(\allowbreak{}lines.\allowbreak{}Add,\allowbreak{}
  [event\allowbreak{}Id],\allowbreak{} Log\allowbreak{}Level.\allowbreak{}Debug)},
  restricted to the plugin's event IDs \\
\end{datatable}

\begin{sourcecode}[Debugging snippets (\allowbreak{}checked in tests/\allowbreak{}.\allowbreak{}.\allowbreak{}.\allowbreak{}/\allowbreak{}Debugging\allowbreak{}Tests.\allowbreak{}cs)]{csharp}
using var ctx = CreateContext();

// 1. Model: annotations, results of conventions, type mappings
var model = ctx.GetService<IDesignTimeModel>().Model;
Console.WriteLine(model.ToDebugString(MetadataDebugStringOptions.LongDefault));

// 2. Services: which replacement won?
Console.WriteLine(ctx.GetService<IMigrationsSqlGenerator>().GetType());

// 3. Conventions: is mine in the list?
var conventions = ctx.GetService<IConventionSetBuilder>().CreateConventionSet();
Console.WriteLine(string.Join("\n", conventions.ModelFinalizingConventions));

// 4. Queries: LINQ tree before, SQL after translation
var query = ctx.Orders.Where(o => o.TenantId == EF.Functions.CurrentTenant());
Console.WriteLine(query.Expression.Print());
Console.WriteLine(query.ToQueryString());
\end{sourcecode}

\begin{tip}[Reproduce in a test, not in the app]
  Almost every plugin problem can be reproduced without a database: build a context with the
  plugin and look at the model, the resolved services or
  \code{To\allowbreak{}Query\allowbreak{}String(\allowbreak{})}. Such a test iterates faster
  than the application and remains as a regression test afterwards.
\end{tip}
